### Naresh Zoom Recorder — Mobile Quick Note

- **Cloud Scheduler Web App (24/7):** https://class-scheduler.class-scheduler.workers.dev/
  - Sign in with GitHub once.
  - Set daily, weekly, or one-time class schedules in IST.
  - Advance Java: `18:00` - `19:30` (cuts cleanly at 7:30 PM).
  - React JS: `19:30` (starts right after).
  - Tap **▶️ Test Run Now** from your phone anytime without opening GitHub!
  - Runs on Cloudflare 24/7 — never paused by GitHub's 60-day inactivity timer!

- **GitHub Workflow Link:** https://github.com/venkatmarturi11/naresh-zoom-recorder/actions/workflows/record-class.yml
- **Telegram Channel / Bot:** Recordings delivered to **`@Meeting_recorder_bot`**

#### 1. Run Manually from Mobile
1. Open the Web Scheduler (https://class-scheduler.class-scheduler.workers.dev/) and tap **▶️ Test Run Now**, OR:
2. Open the GitHub workflow link above in your mobile browser (or **GitHub** app → repo **Actions** → **Record class**).
3. Tap **Run workflow**.
4. *(Optional)* Enter `class_keyword` (e.g., `React JS` or `Advance Java|Advanced Java`), `class_start` (`HH:MM` in IST, e.g. `19:30`, or `now` to join an ongoing class immediately), `class_end` (e.g., `19:30` hard stop). Leave blank to use defaults.
5. Tap the green **Run workflow** button and watch Telegram for updates.
